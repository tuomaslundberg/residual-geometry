Place coding

1–6 or FUAENW code & advance   / note   Esc leave note   ←→ move   G next uncoded
Code what the text is mainly about — not its language, not its site.
FIFinland: Finnish places, institutions, people, events, Finnish everyday life
USthe United States
ANGanother English-speaking country (UK, Ireland, Canada, Australia, NZ …)
ELSEsome other place (another country, the EU, the world in general, a named elsewhere)
NONEno particular place (generic how-to, product text, abstract topic)
WRONGnot in the expected language (a wrong-language page the filter missed)

If two apply, pick the dominant one and write the other in the note. Order is random: any first N coded items are a fair subset; ~150 already give usable counts.
